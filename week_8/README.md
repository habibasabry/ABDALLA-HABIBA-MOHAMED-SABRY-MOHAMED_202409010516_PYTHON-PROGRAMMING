
## Description
A simple Python program that demonstrates modular programming by separating the application into different modules.

## Files
- `main.py` - Runs the application.
- `customer.py` - Collects customer information.
- `receipt.py` - Calculates and prints the receipt.

## How to Run

```bash
python main.py
```

## Features
- Accepts customer details
- Calculates subtotal, service charge (5%), and delivery charge
- Displays a formatted receipt
